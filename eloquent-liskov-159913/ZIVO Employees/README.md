# ZIVO Employees

Standalone employee operations app for the ZIVO Employees brand.

## Open the app

Open `index.html` in a browser. No install step is required.

## Included

- Employee dashboard and manager queue
- Searchable employee directory
- Weekly schedule board
- Time clock demo with local saved state
- Payroll approval checklist
- Employee request inbox
- Document and workspace settings views

The app uses the logo assets from `/Users/viyitta/Downloads/ZIVO Employees` and keeps all code in this folder.
