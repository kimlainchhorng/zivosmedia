**What changed (both display-only-attr / className):**
- `aria-pressed={tab === t.id}` — the active tab is conveyed **only** by background gradient (`bg-ig-gradient text-white` vs `bg-secondary`); screen readers need the toggle-button semantic. Same category as `aria-expanded` on GroceryOrderHistory expand buttons and `aria-pressed` on GroceryOrderHistory filter tabs — both confirmed in-scope.
- Appended to cn() **base** string: `active:scale-[0.97] focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring`
- `transition-all` already present (covers both the `hover:bg-muted` fade and the `active:scale` transform) — no transition change needed.

**Tier rationale — `[0.97]` is correct:** These are chip/filter-tier segmented tabs (`h-10 rounded-xl text-xs font-bold`), same tier as the GroceryOrderHistory filter chips and the menu-row/share-link controls on other slices. The `[0.98]` tier is for wider card-level CTAs (Apply button, store-link cards). `[0.99]` is for full-width flush rows. `[0.97]` is right for compact segmented selectors.
