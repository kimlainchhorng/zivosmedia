### CoinTransfersPage — 1 edit

**File:** `src/pages/CoinTransfersPage.tsx`

**Location:** The filter tab `<button>` at ~L175 (the `.map()`'d button inside the `tabs.map((t) => (` block).

**Before:**
```tsx
className={cn("flex-1 h-10 rounded-xl text-xs font-bold transition-all inline-flex items-center justify-center gap-1.5", tab === t.id ? "bg-ig-gradient text-white shadow-sm" : "bg-secondary text-foreground hover:bg-muted")}
```

**After:**
```tsx
className={cn("flex-1 h-10 rounded-xl text-xs font-bold transition-all inline-flex items-center justify-center gap-1.5 active:scale-[0.97] focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring", tab === t.id ? "bg-ig-gradient text-white shadow-sm" : "bg-secondary text-foreground hover:bg-muted")}
```

And add `aria-pressed={tab === t.id}` as a display-only attribute on the same `<button>`:
```tsx
<button key={t.id} type="button" onClick={() => setTab(t.id)} aria-pressed={tab === t.id} className={cn(…)}>
```

**Why `[0.97]`:** These are `flex-1` pill-tabs — narrower than a full-width card but wider than an icon button. `[0.97]` is the correct chip/small-text-link tier (matches the `JobPostingDetailPage` "All gigs" back-link tier). `[0.98]` would be too subtle for a segmented control; `scale-95` is for icon-only buttons.

**Why `aria-pressed`:** The active tab is conveyed **only** visually via `bg-ig-gradient` — no `aria-current="page"` (not a navigation tabpanel), no `aria-selected` (not a tablist). `aria-pressed` is the correct toggle-button pattern for a filter that changes the visible list. This is a display-only attribute (same category as `aria-expanded` on the GroceryOrderHistory disclosure toggle, which was confirmed in-scope).
