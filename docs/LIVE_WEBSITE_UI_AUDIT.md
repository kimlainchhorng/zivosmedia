3. `zivodriver.com` is not a driver landing page and lacks all driver acquisition/requirements/payout/legal content. P1.
4. `zivobusiness.com` and `zivoemployee.com` show generic ZIVO/feed surfaces instead of domain-specific products. P1/P2.

6. No captured screen contains a consistent `ZivoChat support` entry. P1.
7. Payment, billing, wallet, checkout, payout, and webhook routes lack a shared payment/billing identity. P1.
8. Protected routes mostly land on generic auth with no route-specific context. P1.
9. Cookie/privacy banner blocks important first-viewport content on multiple mobile and desktop screens. P1.
10. `npm run test:visual` currently fails account safe-area snapshots, so visual QA is not green. P1.

## Recommended First UI Fix PR

After this documentation-only PR, the first UI fix PR should be the `zivodriver.com` landing page. It is a visible public-domain mismatch and already has a clear requested scope: Become a Driver CTA, Continue with Zivosmedia, driver benefits, how it works, requirements, earnings/payouts, Travel-to-Driver connection, support/chat link, real Privacy Policy, and real Terms of Service.
