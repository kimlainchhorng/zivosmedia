# Google Play phone screenshots

This folder is intentionally empty while Android capture remains pending.

Add screenshots only after launching the exact signed ZIVO Play-track build on a supported Android
device. Browser, iOS Simulator, Android Studio preview, debug-build, and design-mockup images are not
Play-track evidence.

## Required set

- Add 2 to 8 PNG or JPEG files.
- Use portrait images with at least 1080 pixels on the shorter side.
- Use numbered names so the Play order is explicit, for example `01-home.png`, `02-social.png`,
  `03-messages.png`, `04-travel-search.png`, and `05-account-privacy.png`.
- Show only features that work in that exact build and account state.
- Remove personal data, test credentials, debug overlays, permission dialogs, broken images, and
  misleading price or availability claims before approval.

The screenshot contract accepts either zero images (truthfully pending) or one complete 2-to-8 image
set. It rejects partial one-image packages and invalid dimensions before the release is described as
store-ready.
